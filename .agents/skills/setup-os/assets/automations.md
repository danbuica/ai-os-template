# Automations

Every task the AI does for the company automatically. **automate-process** adds a row when it builds one.

- **How it runs:** by hand (someone types the skill name), on a schedule (and where: which tool, cloud or this computer), or when something happens.
- **Works in:** which AI tools it works in (Claude Code, Codex, Antigravity).
- **Status:** testing, live, paused or retired.
